# Change Log

## [1.1.1] - 2026-09-06
### Changed
- Replaced `$(play)` icon in the editor toolbar with distinctive `$(keyboard)` icon to avoid visual confusion with the compiler "Run Code" play button.
- Changed activation event to `*` so the status bar button appears immediately without waiting for command execution.
- Increased status bar priority to 1000 for prominent visibility.

## [1.1.0] - 2026-09-06
- Added 1-click status bar & editor title buttons.
- Added smart auto-fallback (no backup file required).
- Added file picker for empty files.

## [1.0.0] - 2026-09-05
- Initial release.
